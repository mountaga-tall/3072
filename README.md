Jeu de fusion cérébral ultra-rapide : 3 → 6 → 12 → 24 → … → 3072.

## Fichiers

- `index.html` : interface
- `style.css` : glassmorphism, responsive et animations
- `script.js` : moteur du jeu, score, chrono, swipe, sons
- `manifest.webmanifest` : PWA
- `sw.js` : cache hors ligne
- `images/` : icônes

## Déploiement GitHub Pages

1. Crée un dépôt GitHub.
2. Mets tous les fichiers de ce dossier à la racine du dépôt.
3. Active GitHub Pages sur la branche `main` et le dossier `/root`.
4. Ouvre le site en HTTPS pour profiter de la PWA et du Service Worker.

Aucune dépendance externe n'est requise.
